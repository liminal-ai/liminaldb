# Skill Scanner Examples

## Overview

A collection of vendored Python example scripts demonstrating how to use the skill-scanner library. The examples cover basic scanning, advanced configuration, batch operations, REST API usage, programmatic integration, and specialized analyzers (behavioral and LLM). Each script is self-contained with a `main()` entry point and serves as reference documentation for skill-scanner consumers.

## Responsibilities

- Demonstrate basic skill scanning with minimal setup (`basic_scan.py`)
- Show advanced scanning with custom scanner creation and severity filtering (`advanced_scanning.py`)
- Illustrate batch scanning of multiple skills (`batch_scanning.py`)
- Provide REST API usage patterns including health checks, directory scans, zip uploads, and batch operations (`api_usage.py`)
- Show programmatic integration with findings analysis (`programmatic_usage.py`, `integration_example.py`)
- Demonstrate behavioral analyzer capabilities (`behavioral_analyzer_example.py`)
- Demonstrate LLM-based analyzer capabilities (`llm_analyzer_example.py`)
