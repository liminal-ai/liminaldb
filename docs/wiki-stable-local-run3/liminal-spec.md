# Liminal Spec

## Overview

Build and validation tooling for the Liminal prompt format specification. This module contains standalone scripts for compiling the spec, validating prompt documents against it, and a test suite ensuring build correctness.

## Responsibilities

- Build/compile the Liminal prompt format specification from source definitions
- Validate prompt documents against the compiled specification
- Provide automated tests to verify spec build integrity
