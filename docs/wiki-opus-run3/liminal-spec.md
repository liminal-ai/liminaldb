# Liminal Spec

## Overview

Build and validation tooling for the liminal-spec format. This module provides scripts to compile spec source files into a distributable format and to validate spec documents against the expected schema. A comprehensive test suite covers the build process.

## Responsibilities

- Build liminal-spec source files into a compiled output format
- Validate liminal-spec documents for schema correctness and structural integrity
- Provide automated tests for the build pipeline
