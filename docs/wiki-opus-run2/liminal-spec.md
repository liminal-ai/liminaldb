# Liminal Spec

## Overview

Specification build and validation tooling for the LiminalDB spec. This module contains scripts to build the spec from source, validate the resulting output, and a test suite to verify build correctness.

## Responsibilities

- Build the LiminalDB specification from source files
- Validate the built specification for correctness and completeness
- Provide automated tests for the spec build process
