# Liminal Spec

## Overview

Build and validation tooling for the LiminalDB spec format. This module contains scripts to compile spec definitions into their output format, validate spec correctness, and a test suite covering the build process.

## Responsibilities

- Build/compile LiminalDB spec definitions into their distributable format
- Validate spec files for correctness and conformance
- Test coverage for the spec build pipeline
