# Skill Scanner Examples

## Overview

A collection of vendored Python example scripts demonstrating various ways to use the skill scanner library — from basic one-off scans to advanced configuration, batch processing, behavioral analysis, LLM-powered analysis, and REST API integration. Each script is a standalone runnable example with its own `main()` entrypoint.

## Responsibilities

- Demonstrate basic skill scanning with minimal setup (`basic_scan.py`)
- Show advanced scanner configuration and severity filtering (`advanced_scanning.py`)
- Illustrate REST API usage including health checks, directory scans, zip uploads, and batch operations (`api_usage.py`)
- Provide batch scanning examples for processing multiple skills at once (`batch_scanning.py`)
- Showcase behavioral analyzer capabilities (`behavioral_analyzer_example.py`)
- Demonstrate LLM-powered analysis integration (`llm_analyzer_example.py`)
- Present a full integration example combining multiple scanner features (`integration_example.py`)
- Show programmatic usage with custom finding analysis (`programmatic_usage.py`)
