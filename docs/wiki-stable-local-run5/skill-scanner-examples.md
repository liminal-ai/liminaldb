# Skill Scanner Examples

## Overview

A collection of vendored Python example scripts demonstrating various usage patterns of the skill-scanner library. The examples cover basic scanning, advanced configuration, batch processing, REST API interaction, behavioral analysis, LLM-based analysis, integration patterns, and programmatic usage.

## Responsibilities

- Demonstrate basic skill scanning with minimal configuration
- Show advanced scanning with custom scanner creation and severity filtering
- Illustrate REST API usage including health checks, directory scans, zip uploads, and batch operations
- Provide batch scanning examples for processing multiple skills
- Showcase behavioral analyzer and LLM analyzer integrations
- Demonstrate programmatic usage with finding analysis helpers
- Serve as an integration example combining multiple scanner capabilities
