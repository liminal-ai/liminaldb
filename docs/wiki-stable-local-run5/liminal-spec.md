# Liminal Spec

## Overview

Build and validation tooling for the `liminal-spec` package. This module contains scripts that compile and validate the Liminal specification, along with tests ensuring the build process works correctly.

## Responsibilities

- Build the liminal-spec package from source definitions
- Validate the spec output for correctness and completeness
- Test the build pipeline to prevent regressions
