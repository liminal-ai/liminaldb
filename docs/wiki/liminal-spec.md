# Liminal Spec

## Overview

Build and validation tooling for the `liminal-spec` package. This module contains scripts that compile the Liminal specification artifacts and validate them for correctness, along with a comprehensive test suite for the build process.

## Responsibilities

- Build liminal-spec package artifacts from source specification definitions
- Validate specification outputs for structural correctness and completeness
- Provide automated test coverage for the build pipeline
