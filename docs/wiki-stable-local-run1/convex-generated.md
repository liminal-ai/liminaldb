# Convex Generated

## Overview

Auto-generated Convex framework files that provide typed API definitions, data model types, and server function constructors. These files are produced by the Convex CLI (`npx convex dev` / `npx convex deploy`) and should never be edited manually. They serve as the foundational type layer that virtually every server-side and client-side module imports from.

## Responsibilities

- Provide typed API references (`api`, `internal`, `components`) for calling Convex functions from both server routes and client code
- Export typed server function constructors (`query`, `mutation`, `action`, `internalQuery`, `internalMutation`, `internalAction`, `httpAction`) that bind the project's schema to Convex's generic builders
- Define the project-specific `DataModel` type used by model layer modules for typed database access
- Act as the single generated bridge between the Convex framework and all hand-written application code
