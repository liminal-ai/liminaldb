# Skill Scanner: Examples

## Overview

A collection of standalone Python example scripts demonstrating how to use the skill scanner at various levels of complexity — from basic single-directory scans to batch processing, advanced configuration, programmatic result analysis, HTTP API consumption, and specialized analyzer integrations (behavioral, LLM, integration). Each script is self-contained with its own `main()` entrypoint.

## Responsibilities

- Demonstrate basic single-directory scanning via `basic_scan.py`
- Show batch scanning of multiple skill directories via `batch_scanning.py`
- Illustrate advanced scanner configuration and severity filtering via `advanced_scanning.py`
- Provide programmatic result analysis patterns via `programmatic_usage.py`
- Document HTTP API usage including health checks, directory scans, zip uploads, and batch operations via `api_usage.py`
- Showcase behavioral analyzer integration via `behavioral_analyzer_example.py`
- Showcase LLM analyzer integration via `llm_analyzer_example.py`
- Showcase end-to-end integration example via `integration_example.py`
